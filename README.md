# 🧠 Simple Quiz

Welcome to **Simple Quiz**, a lightweight and interactive web-based quiz application. This project provides users with a fun way to test their knowledge with multiple-choice questions.

---

## ✨ Features

✔ **User-Friendly Interface** – Clean and simple design for an engaging experience.  
✔ **Multiple Choice Questions** – Answer a set of predefined questions.  
✔ **Instant Scoring** – Get your score immediately after submitting the quiz.  
✔ **Responsive Design** – Optimized for both mobile and desktop users.  

---

## 🛠️ Technologies Used

🔹 **HTML** – Defines the structure of the quiz.  
🔹 **CSS** – Enhances styling and layout.  
🔹 **JavaScript** – Handles quiz logic and scoring functionality.  

---

## 📂 File Structure

📂 `index.html` – The main file containing quiz questions.  
🎨 `styles.css` – Stylesheet for designing the quiz layout.  
📜 `script.js` – Handles user responses and calculates scores.
